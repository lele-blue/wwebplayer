# wwebplayer

This repo is the webplayer and packer of the wwise extractor + player I built a few years ago to procrastinate a Math exam.

It uses xml export files from wwiser as input. There are some hardcoded id->string mappings for Destiny 2, those can be extended

This is very much a WIP since this code is in the middle of a bigger restructure that i never finished, but the LLM of your choice should be able the fix the timeline issues this currently has.
